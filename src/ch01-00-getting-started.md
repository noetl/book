# Getting Started

<span class="status status-real">REAL</span>

This chapter gets NoETL onto your machine and runs your first
playbook. You need no server, no database and no cluster: the `noetl`
command-line tool has a **local runtime** that runs a playbook inside
the CLI process.

- [1.1 Installation](ch01-01-installation.md): three ways to install
  the CLI, and which version each one gives you today.
- [1.2 Hello, Playbook](ch01-02-hello-playbook.md): the smallest valid
  playbook, and one with an input.
- [1.3 Running It Locally](ch01-03-running-locally.md): `noetl run`,
  reading its output, and the local event trail.

Every example in this chapter is in the book's repository under
`examples/ch01/`, and CI runs it with **NoETL CLI v6.4.0**.
