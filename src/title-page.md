# The NoETL Book

*Declarative, event-sourced orchestration — from your first playbook to
distributed, edge and agent runtimes.*

This book is written iteratively, alongside the system it describes.
Every chapter carries a status badge so you always know whether you are
reading about something that ships today or something that is still
being built. See [How to Read This Book](ch00-01-how-to-read.md).
